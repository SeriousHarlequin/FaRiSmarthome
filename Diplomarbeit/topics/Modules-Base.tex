This chapter describes how the hardware is constructed and changed over time.
The revisions of the modules are presented backwards in this document, from
the latest to the oldest design. 

\section{Basic Module} \label{sec:basic_module}
    Every Node (except the bridge node) consists of the same base module. It's
    capable of measuring the ambient temperature and controlling four RGB-LEDs.
    The functionality of the basic module can be extended by attaching another
    module to the base module. 

    There were multiple revisions of the basic module. Revision 1.0 was designed to
    be a very rough prototype to test the functionality and concept of an attachable 
    battery. Revision 2.x was designed to be a more polished version of the basic node, 
    all the other modules were designed and developed alongside this version.
