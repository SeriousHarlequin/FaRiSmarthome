\section{Battery Module} \setAuthor{Richard Krammer}

The battery module is used to power the basic node, without the need
to connect a USB-C cable meaning when no power outlet is available. This module 
can be attached to the Base Module alongside the motion detector module.

Following components are required to fulfill the requirements:

    \begin{itemize}
        \item 1. Battery
        \item 2. Power-Managment-System
        \item 3. DC-DC Converter
        \item 4. On/Off switch
    \end{itemize}
