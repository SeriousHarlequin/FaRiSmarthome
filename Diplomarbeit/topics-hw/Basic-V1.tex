\subsection{Hardware - V1.1}
    Version 1.x of the basic module was intended to be a ruff prototype to test the concept of a 
    plugable battery powered module. For this reason only the battery module was designed for this
    version. Version 1.0 was never manufactured, but the design was used as a base for the
    version 1.1. The version 1.1 was manufactured and tested. 

    \subsubsection{Module Connector}
        The module connector has four connectors, one for the battery and three for the
        "modules".

        \begin{figure}[H]
            \centering
            \includegraphics[width=0.6\textwidth]{assets/HW/NodeV1.1-ESP-C3.png}
            \caption{Microcontroller and module connector implemented in the schematic.}
            \label{fig:node-module-connectorV1.1}
        \end{figure}

        


        To connect a module there is a 10 pin header with IO-ports and a 6 pin header 
        for supplying power. It was not intended to design a module, besides the battery module,
        for this version. It was planned to be used in testing as a development board and connecting
        the sensors over jumper wires.
        
        \begin{figure}[H]
            \centering
            \includegraphics[width=0.5\textwidth]{assets/HW/NodeV1.1-Battery-Connector.png}
            \caption{Battery connector implemented in the schematic.}
            \label{fig:node-battery-connectorV1.1}
        \end{figure}

        This is used to disable the linear voltage regulator on the basic module with the MOSFET Q1.

    \subsubsection{DC-DC Converter}
        
        To convert the 5V from the USB port to 3.3V a LM7805 linear regulator was used. This regulator
        would then be bypassed by the battery module when connected. Then the 3.3V would be supplied by the
        battery module. The 5V was also used to charge the battery.

        The LS33V is turned off by a P-Channel MOSFET when the battery module was connected.

        \begin{figure}[H]
            \centering
            \includegraphics[width=0.6\textwidth]{assets/HW/NodeV1.1-DC-DC.png}
            \caption{DC-DC Converter implemented in the schematic.}
        \end{figure}

    \subsubsection{Serial-To-USB Converter}
        The Serial-To-USB converter was deemed to be unnecessary since the MCU could also be programmed 
        over native USB, it was removed from later versions.

    \subsubsection{PCB}

        The PCB of the basic module is a 2-layer board with a size of 75x30mm. 
        The PCB is designed to be mounted on the battery module. The PCB layout of the basic 
        module is shown in figure \ref{fig:basic-module-pcb-V1.1}.

        \begin{figure}[H]
            \centering
            \includegraphics[width=0.6\textwidth]{assets/HW/PCB-NODE-V1.1.png}
            \caption{PCB of the basic module V1.1. [Red - Frontside, Blue - Backside]}
            \label{fig:basic-module-pcb-V1.1}
        \end{figure}

        The most noticeable change to the board is the ESP32-C3's antenna, which 
        extends beyond the board's edge. In later versions the antenna stayed within the PCB
        to keep the size small and to make the designing of the case easier.

\subsection{Hardware - V1.0}
    This version had a finished schematic, but the PCB was never finished/further development into 
    version 1.1. The schematic is very similar to the version 1.1. Following components were different 
    in this version:
    
    \begin{itemize}
        \item 1. Micro USB connector was used.
        \item 2. No power headers.
        \item 3. Different battery monitoring.
    \end{itemize}

    \subsubsection{Micro USB Connector}
        The frist version of the basic module was designed to be powered over a micro USB connector.

        The power header J5 as seen in figure \ref{fig:node-module-connectorV1.1} is not implemented 
        in the first version of the basic module.

    \subsubsection{Battery Monitoring}
        The battery monitoring was done with a voltage divider with two 22kOhm resistors. 

        \begin{figure}[H]
            \centering
            \includegraphics[width=0.4\textwidth]{assets/HW/NodeV1.0-Battery-Check.png}
            \caption{Battery implemented in the schematic.}
        \end{figure}

        In version 1.1V the resistor R3 and R4 were increased to 100kOhm to reduce the current 
        consumption of the voltage divider and a 100nF capacitor was added to filter the voltage.
